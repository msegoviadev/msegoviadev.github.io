A CLI tool that shrinks OpenAPI and AsyncAPI specs into a compact `.mind` format built for LLM consumption. Drop a bloated YAML file in, get back something 60-80% smaller that still preserves every endpoint, schema, and constraint that actually matters.

**Tech Stack:** TypeScript, Bun

**Status:** Active development, MIT License
